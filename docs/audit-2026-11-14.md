# Audit complet de FlashMiam (14 novembre 2026)

Périmètre : la carte (`index.html`), l'application (`web/`), la base et les fonctions serveur Supabase, la publication
(Vercel, GitHub Actions) et le site en ligne https://flashmiam.fr. Écrans parcourus sur téléphone et ordinateur, en
mode jour et nuit, comme client et comme restaurateur.

Les écrans connectés ont été testés avec un Supabase **simulé dans le navigateur de test** : aucune donnée en ligne
n'a été lue ni modifiée pour cela.

## En bref

La base est solide : sécurité du serveur sérieuse (RLS sur toutes les tables, fonctions serveur qui vérifient
elles-mêmes la session, politique CSP à empreintes), accessibilité très bonne, mode nuit soigné, mise en page
téléphone et ordinateur bien pensée, vérifications automatiques au vert.

**Le problème le plus important trouvé** : en production, la carte montrait **6 restaurants fictifs** (Le Camion
Vendéen, Kebab Clemenceau…) à de vraies adresses, avec de **fausses promotions** (« Boisson offerte dès 8 € »,
« -15 % étudiants »), sans rien qui les distingue des vrais, plus la « Restaurant de test 1 ». La pastille rouge des
offres annonçait une dizaine d'offres qui n'existent pas. Risque d'image (quelqu'un se déplace pour rien) et risque juridique
(offres commerciales trompeuses). **Corrigé** (voir ci-dessous).

## Ce qui a été vérifié

- **Supabase** : alertes de sécurité, de performance et de santé (aucune alerte bloquante ; 3 remarques normales :
  tables réservées au serveur, sans règle d'accès volontairement) ; RLS active sur les 32 tables ; 8 fonctions serveur
  relues (chacune vérifie la session ou une signature elle-même) ; 23 migrations appliquées.
- **Code** : aucune insertion de texte venant des utilisateurs en HTML (tout passe par `textContent`) ; CSP à
  empreintes vérifiée (un script injecté est bien bloqué) ; politique recalculée après les modifications.
- **Tests** : lint et construction de l'application OK ; 79 tests des fonctions serveur OK. Les 243 tests des règles
  de la base (`npm run db:test`) n'ont pas été relancés : ils demandent un PostgreSQL local, absent ici.
- **Site en ligne** : HTTPS, HSTS, `http://`, `www.flashmiam.fr` et `flashmiam.com` renvoient bien vers
  `https://flashmiam.fr` ; page 404, `robots.txt`, `sitemap.xml` OK ; compression brotli active.
- **GitHub** : toutes les vérifications automatiques au vert ; sauvegarde nocturne réussie.

## Recommandations (non faites : à décider)

### Priorité haute

1. ~~**Laisser voir la carte sans compte.**~~ **Fait le jour même** (demande validée) : carte, fiches, menus, avis et
   stories visibles sans compte ; 3 offres visibles, les autres floutées avec « Créer un compte pour voir la suite » ;
   barre fixe « Créer mon compte gratuit » en bas de l'écran ; suivre, avis, « j'aime », QR code et notifications
   ouvrent la création de compte. Voir `README.md`, « Visiteurs sans compte ».
2. **Réglages en attente** (déjà notés dans `web/docs/SECURITE-ETAT.md`, à faire dans les consoles) :
   - Google Cloud : ajouter `https://flashmiam.fr` (et `www`, `.com`) aux origines du client OAuth — **la connexion
     Google ne marche pas sur l'adresse principale** tant que ce n'est pas fait ; Supabase › URL Configuration ;
   - SMTP dans Supabase : sans lui, **les codes des restaurateurs et « mot de passe oublié » ne partent pas** ;
   - Turnstile (anti-robots) avant l'ouverture au public ; couper les anciennes clés `anon` / `service_role` ;
   - secrets de la sauvegarde ; informations légales entre crochets (`web/lib/legal/site.ts`) ; Whop.
3. **`www.flashmiam.com` ne répond pas** (enregistrement DNS manquant chez le registraire).

### Priorité moyenne

4. **Zoom de la page bloqué** (`maximum-scale=1`) : l'outil d'accessibilité le classe « critique » (personnes
   malvoyantes). À retirer après un essai sur Android (la carte garde son propre zoom).
5. **Poids de la page** : `index.html` fait 735 Ko (195 Ko compressé), dont beaucoup de commentaires. Une
   minification à la publication réduirait le téléchargement et le temps de démarrage sur les petits téléphones.
6. **Couleurs** : le logo est rouge-orange, l'interface reprend le bleu de Google. Harmoniser la couleur principale
   avec le logo renforcerait la marque.
7. **Dépendances (Dependabot)** : fusionner `lucide-react` (n° 13), `eslint` (n° 14) et les actions GitHub (n° 1) ;
   **ne pas** fusionner `@types/node` 26 (n° 12) : le site est construit avec Node 22.
8. `pwa-nantes.vercel.app` sert le même site sans renvoyer vers `flashmiam.fr`. À rediriger une fois la connexion
   Google réglée sur `flashmiam.fr`.

### Faible
